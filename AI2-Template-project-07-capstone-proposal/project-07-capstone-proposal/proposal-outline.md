## Checkpoint Self-Assessment

### Before Starting (Checkpoint 1)
- [ ] Identified real-world problem
- [ ] Researched existing solutions
- [ ] Confirmed idea uses AI/ML from course
- [ ] Discussed feasibility with team

### After System Design (Checkpoint 2 & 3)
- [ ] Clear problem statement with evidence
- [ ] 2-3 SMART objectives
- [ ] 3-4 well-defined modules
- [ ] Tools and technologies selected
- [ ] 2-3 algorithms with justifications
- [ ] User groups identified
- [ ] Social impacts documented

### After UI Design (Checkpoint 4)
- [ ] All sketches complete and approved
- [ ] Final mockups created
- [ ] UI explanations written

### Final Review
- [ ] Minimum 5 pages (excluding cover, ToC, UI, references)
- [ ] All sections complete
- [ ] Document proofread
- [ ] Team has reviewed and approved
